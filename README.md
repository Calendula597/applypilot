# 投递副驾（ApplyPilot）

自动识别招聘表单，一键把你的简历填进去的 Chrome / Edge 扩展（Manifest V3）。

## 功能

- **字段齐全**：档案结构对齐主流简历编辑器——3 个扁平区（个人信息 50 项、求职意向 9 项、技能专长 5 项）加 11 个列表区（教育经历 28 项、工作经历 15 项、实习经历 12 项、项目经历 13 项、干部任职 6 项、外语能力 7 项、证书 3 项、获奖经历 8 项、专利信息 6 项、论文发表 6 项、家庭情况 10 项），合计 14 个区块 178 个字段；识别词典与字段一一对应（通用 64 项 + 区块 114 项）。
- **识别**：纯本地规则引擎——中英文关键词词典匹配 label / placeholder / name / id，叠加 DOM 启发式（aria-*、label[for]、祖先容器短文本、前置兄弟）与区块上下文（同一个词在不同区块含义不同，按区块切换词典）。
- **填充**：文本框、下拉（学历/性别/是否/工作年限走同义词映射，如「本科 → 统招本科」）、单选、日期（格式归一为控件要求）、自定义下拉（antd 等：点触发器 → 扫弹层 → 点选项）、多段经历动态列表（按视觉行聚类 + 自动点「添加」增行）。React/Vue 受控组件用原生 setter + input/change 事件，已填字段蓝色高亮。
- **岗位雷达（givemeoc.com）**：在校招汇总表页点插件 →「🎯 岗位雷达」，按你的档案（期望职位/城市/毕业届别/学历/技术栈）给表格企业打分排序——岗位词、技术栈、城市命中加分，届别不符降权，学历不达标、已投递、已截止的直接排除，临近截止标「急」。面板支持「再扫 5 页」自动翻页抓取。「去投递」自动打开该公司报名页并在加载完成后触发一键填充（首次使用需授权一次「所有网站」可选权限；若目标页是职位列表页而非表单页，会提示你点开具体岗位后再一键填充）。
- **导出 PDF**：管理页「导出 PDF」把当前档案排成 A4 版式简历，经浏览器「另存为 PDF」导出（中文渲染原生可靠，无需内嵌字体）。
- **生成英文简历**：把当前档案按英文简历惯例精选——Summary 压缩成一两句、教育只留最近两段、经历描述按「量化 + 能力动词」评分只留最强 3 条、项目取最强的 2 个、奖项只留国家级/省级，并自动省略家庭/政治面貌/证件号/身高体重等英文简历禁忌项。学历/职位/城市/专业等走内置词典；机构名与经历描述可在「LLM API 设置」里配置 OpenAI 兼容接口（默认 DeepSeek）后自动翻译。英文档案可直接用于英文表单一键填充，导出 PDF 时自动切换英文版式（Summary 置顶、英文月份、Present、衬线字体）。
- **导入 PDF 简历**：管理页「⬆ 导入 PDF 简历」——pdf.js 本地提取文本 + 启发式解析（姓名/联系方式/教育/工作/实习/项目/技能/获奖/证书等），自动创建为新档案。解析是尽力而为，导入后请检查补全；全程不联网。
- **LLM 填充兜底**（可选，默认关闭）：开启后，规则引擎认不出的字段会连同表单结构一起送 LLM 做语义映射，再回本地取值填充——请求里只有表单侧描述（label / 占位符 / name / 下拉选项）与「哪些候选字段有值」，**不含简历内容**。填充结果标注「其中 LLM 兜底识别 N 个」，失败时在面板给出原因。
- **内容润色**（可选）：管理页「✨ 润色简历内容」把经历描述、自我评价、技能等自由文本交给 LLM 润色（要求保留数字与事实、动词开头、不虚构），改动逐条预览、可取消勾选，确认后写回当前档案。
- **多档案**：可建多套（如「技术岗版」「产品岗版」「英文版」），popup 里随时切换；旧版档案数据自动迁移到新结构。

## 隐私

简历数据只存在 `chrome.storage.local`，不上传任何服务器。除上述可选的 LLM 功能外零网络请求：

- 三个 LLM 功能（英文翻译 / 填充兜底 / 内容润色）都需你自行配置 API Key，点「保存设置」时才会申请访问该 API 域名的权限；
- 填充兜底走 `content → background → API`，即请求由扩展进程代发（页面里的内容脚本受宿主页 CORS 限制，无法直接调用外部 API）。

## 构建与安装

```bash
npm install
npm run build        # 图标 + 类型检查 + popup/options (vite) + content.js / background.js (esbuild)
```

Chrome / Edge 打开 `chrome://extensions` → 开启「开发者模式」→「加载已解压的扩展程序」→ 选择本项目的 **`dist/`** 目录（不是项目根目录）。

改代码后重新 `npm run build`，回扩展页点卡片上的刷新按钮，再刷新目标网页即可。

## 使用

1. 点扩展图标 →「管理简历」→ 手动填写，或点「⬆ 导入 PDF 简历」自动解析建档，自动保存。
2. 打开任意招聘投递页（公司官网投递表单、Moka、飞书招聘等）。
3. 点扩展图标 → 选档案 → 「⚡ 一键填充」。已填字段会蓝色高亮，并提示「已填 N 个字段 / M 个未处理」及明细。
4. 需要简历文件时：管理页 →「导出 PDF」→ 打印对话框选「另存为 PDF」。

本地验证可直接用 `test/form.html`（浏览器打开即可）。

## 项目结构

```
src/
  shared/     # 跨上下文共用（content / background / popup / options 都会引用）
    types.ts    # Profile 数据模型（14 区块 178 字段）、item 工厂、旧数据迁移
    storage.ts  # Store（多档案 + activeId）读写封装
    messages.ts # 消息协议：FILL_RESUME / OPEN_OC_PANEL / OC_APPLY / SHOW_BANNER / LLM_MAP_FIELDS
    llm.ts      # OpenAI 兼容客户端：llmChat + 翻译 / 字段映射 / 润色
  content/    # 注入页面的识别与填充引擎（esbuild 打成单文件 IIFE）
    rules.ts    # 关键词词典（通用 64 项 + 11 个区块 114 项）+ 学历/性别/是否/年限同义词
    label.ts    # label 文本多策略提取
    scanner.ts  # 控件收集、区块锚点识别、字段分类打分
    filler.ts   # 原生 setter + 事件序列、自定义下拉、多段经历增行、高亮、兜底调度
    llmFill.ts  # LLM 兜底识别：未识别字段 → 字段映射（经 background 代发请求）
    ocPanel.ts  # 岗位雷达：汇总表解析、匹配打分、推荐面板、去投递
  background/ # service worker：去投递 → 打开报名页 → 自动注入填充；代发 LLM 请求
  popup/      # 档案切换 + 一键填充 + 岗位雷达入口 + 结果统计
  options/    # 多档案简历编辑器（全部字段，自动保存）
    export.ts       # A4 版式简历 HTML + 浏览器另存为 PDF（中/英文版式）
    resumeImport.ts # PDF 文本提取（pdf.js）+ 启发式解析为档案字段
    enResume.ts     # 中文档案 → 简洁英文简历的精选与词典翻译
    polish.ts       # 自由文本挑选 + 润色结果写回
scripts/gen-icons.mjs   # 纯 Node 手写 PNG 生成图标，无外部依赖
test/form.html          # 本地测试表单（含动态添加行）
```

## LLM 功能配置

管理页顶部「🤖 LLM API 设置」填 API 地址 / 模型 / Key（OpenAI 兼容，默认 DeepSeek），点「保存设置」时会申请该域名的访问权限（扩展页面绕开 CORS 的前提）。

- **英文翻译**：点「生成英文简历」时联网。
- **填充兜底**：勾选后，点「一键填充」时才会联网；只上传表单字段描述与候选字段名。
- **内容润色**：点「润色简历内容」时联网，上传的是所选自由文本原文。

三者都需自行提供 API Key，未配置时相关按钮会给出提示，其余功能保持离线。单次请求 30 秒超时，填充兜底失败会降级为「未处理」并在面板说明原因，不影响规则引擎已完成的填充。

## 针对新站点调优

识别不准时优先改 `src/content/rules.ts`（加关键词），一般不用动扫描/填充逻辑：

- 基本信息字段 → `BASIC_KEYWORDS`
- 教育段内字段 → `SECTION_FIELD_KEYWORDS.education`；工作段内字段 → `SECTION_FIELD_KEYWORDS.work`
- 区块标题识别 → `SECTION_KEYWORDS`
- 下拉选项对不上 → `DEGREE_SYNONYMS` / `GENDER_SYNONYMS` / `YES_NO_SYNONYMS` / `matchYearsOption`

自定义下拉（antd 等）点不开时，往 `fillCustomControl` 的弹层选择器里补该站点的类名。

开了 LLM 兜底还认不出的字段，多半是档案里没有对应值（候选列表只包含有值的字段），或该控件被判定为不可见。
